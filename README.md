# 🏠 Predicción del Precio de Airbnb en Valencia

Proyecto final Extraccion de datos enfocado en **predecir el precio por noche de alojamientos Airbnb en Valencia** mediante técnicas de Machine Learning.  
El objetivo es estimar el precio realista de un anuncio y detectar si está **sobrevalorado**, **infravalorado** o **a precio justo**.

---

## 📋 Pipeline del Proyecto

1. **Limpieza de datos**  
2. **Carga del dataset limpio**  
3. **Análisis Exploratorio (EDA)**  
4. **Feature Engineering**  
5. **Preprocesamiento para ML**  
6. **Entrenamiento de modelos de regresión**  
7. **Evaluación y selección del mejor modelo**  
8. **Clasificación del precio (justo / sobrevalorado / infravalorado)**  
9. **Preparación para dashboard en Streamlit**

---

## 📊 Dataset

Los datos provienen de **Inside Airbnb**, una plataforma que recopila información pública sobre alojamientos.  
Incluye variables como:

- precio  
- ubicación  
- tipo de propiedad  
- número de habitaciones  
- disponibilidad  
- puntuaciones y servicios
